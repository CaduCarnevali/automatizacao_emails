# Automação de Envio de Emails

Sistema desenvolvido em Python para envio automático de emails com anexos PDF.

## Tecnologias
- Python
- SMTP
- JSON
- dotenv

## Funcionalidades
- Envio automático de emails
- Anexos PDF automáticos
- Modo TESTE e PRODUÇÃO
- Leitura de clientes via JSON

## Como executar

```bash
python envio_email.py
